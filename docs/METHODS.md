# How the calls are made

This document describes exactly how a result is produced, what evidence stands
behind it, and where the method stops being reliable. Read it before using the
output for anything that matters.

## 1. Reference data

All bundled data is generated by `python3 -m fos_cazavi.build_data` from a
single AMRFinderPlus release. The release version in use is recorded in
`fos_cazavi/data/DATA_VERSION.txt` and copied into every JSON summary.

| File | What it is |
|---|---|
| `example_database.fasta` | Nucleotide CDS used to *find* genes in an assembly |
| `chromosomal_reference_cds.fasta` | Curated chromosomal loci, committed so rebuilds are reproducible |
| `reference_proteins.faa` | Per gene **and organism** protein references that *define residue numbering* |
| `point_mutations.tsv` | Curated point mutations from AMRFinderPlus |
| `blaKPC_alleles.tsv` | Every NCBI blaKPC allele, expressed as its differences from KPC-2 |

Finding a gene and numbering its residues are deliberately separate jobs. A
nucleotide reference is good enough to locate a locus; it is *not* good enough
to number residues, because the wild-type sequence differs between species.

**Validation at build time and at load time.** Every mutation position is
checked against the reference protein it is numbered in. A row whose stated
reference residue does not match that protein is dropped and reported, both
when the data is built and again when it is loaded at runtime. A silently wrong
position cannot reach a result.

## 2. Finding genes

`blastn` searches the assembly against the nucleotide database. Hits below the
identity and coverage thresholds are discarded. Overlapping hits at one locus
are ranked by bitscore and only the best-scoring reference is kept, so each
locus is called against the reference it actually matches most closely. The
search keeps a large number of target sequences rather than the BLAST default,
because a locus legitimately hits every allele of its family and capping the
list would hide the true best match.

## 3. Calling variants

For each retained hit:

1. The **full gene span** is recovered from the contig. BLAST reports only the
   aligned region, so the assembly bases upstream and downstream that
   correspond to the rest of the reference gene are added back. If the contig
   ends first, the gene is flagged `Complete = no (contig boundary)`.
2. The span is translated in the reference's reading frame and orientation.
3. The translated protein is aligned to the reference protein, and the
   differences are read off the alignment: substitutions, in-frame deletions
   (adjacent ones merged, e.g. `E166_L167del`), insertions (`insPNK@267`),
   premature stop codons, frameshifts and truncations.

Because the comparison walks a real alignment, an indel does not shift the
calls after it. Because it reports the residue actually observed, a call is
never a label like `G55D/*` that does not say what was found.

### Numbering

Class A beta-lactamases (KPC, SHV, OXA, CTX-M) are reported in **standardised
Ambler numbering**, which omits positions 58 and 253. Sequential residue 178 in
a KPC coding sequence is therefore Ambler position 179 — the `D179Y` of the
literature. Every other gene is reported in plain sequential numbering against
its reference protein.

This is also why some allele definitions here differ by one from older papers:
those papers numbered sequentially without allowing for the absent positions.
See *Standardized numbering and alignment of the KPC family of β-lactamases*,
Antimicrob Agents Chemother (2025), doi:10.1128/aac.01868-25.

### Loss of function

A chromosomal gene is called loss-of-function when its product carries a
premature stop, a frameshift, or is shortened by more than
`variants.TRUNCATION_TOLERANCE` (5%). The 5% margin stops in-frame indels of a
few residues — which produce working proteins — from being reported as
knockouts.

## 4. Which changes get reported as resistance mutations

| Gene type | What is reported |
|---|---|
| Acquired beta-lactamase, fosA-family enzyme | Every difference from the reference allele. The reference is the canonical allele of that same gene, so a difference is a real variant. |
| blaKPC | Every difference is listed; only changes the ceftazidime-avibactam assessor recognises are reported as *resistance* mutations. |
| Chromosomal gene | Only positions curated for the **declared organism**, plus loss of function. |

Chromosomal point mutations require `--organism`. Without it, ordinary
between-species sequence differences would be indistinguishable from resistance
mutations — this is precisely the failure mode that makes naive tools report,
say, a dozen "mutations" in *Klebsiella* `ompK36` scored against an *E. coli*
reference. Loss of function is species independent and is still detected
without `--organism`.

Supported organisms: `Escherichia`, `Klebsiella_pneumoniae`,
`Pseudomonas_aeruginosa` (AMRFinderPlus taxgroup names).

## 5. blaKPC allele typing and ceftazidime-avibactam

The observed change set is matched against every NCBI blaKPC allele. An exact
match names the allele (`blaKPC-31`, `blaKPC-66`, …); anything else is reported
as `novel blaKPC variant (…)` with its changes listed.

The ceftazidime-avibactam call then uses two lines of evidence:

1. **Allele identity** — NCBI curates certain alleles as
   *inhibitor-resistant extended-spectrum* enzymes. An exact match to one of
   these is high-confidence evidence.
2. **Mechanism** — changes in the structural hotspots:
   * Omega loop, Ambler **164–179** — in-frame deletions and insertions here,
     and the documented substitutions (D179Y/N/G/V, L169P/Q/M, E166K), are
     high-confidence.
   * Active-site region, Ambler **237–243** — V240G/A and T243M/A are
     high-confidence.
   * Insertion loop, Ambler **266–276** — in-frame insertions are reported, but
     as uncertain.

A change that falls in a hotspot but is not documented produces
**Indeterminate**, not Resistant.

**Metallo-beta-lactamases** (NDM, VIM, IMP, SPM, GIM, SIM) are not inhibited by
avibactam, so their presence alone gives a Resistant call regardless of any KPC
present. OXA-48-like enzymes *are* inhibited by avibactam and do not on their
own produce a Resistant call.

### Contributory chromosomal changes

Some chromosomal changes raise ceftazidime-avibactam MICs by reducing drug entry
or altering the target, rather than by defeating avibactam. They amplify a
beta-lactamase instead of conferring resistance themselves, so they are scored
as **uncertain evidence**: on their own they give `Indeterminate`, and alongside
a KPC escape variant they appear as supporting context. They never produce a
Resistant call by themselves.

| Finding | Condition |
|---|---|
| Curated mutation in `envZ`, `ftsI` or `ompK36` whose AMRFinderPlus subclass mentions AVIBACTAM (e.g. `envZ_R397C`, `ftsI_L367Q`, `ftsI_A413V`, `ompK36_A21V`) | `--organism` declared |
| Loss of function in the porin `ompK36` | A blaKPC is also present, and the gene is complete |

Two deliberate exclusions:

* **OmpK35 is not scored.** Its truncation is near-universal background in
  clinical *K. pneumoniae*; scoring it would make `Indeterminate` the default
  for most isolates without discriminating anything. It is still detected and
  reported.
* **OmpK36 loss is scored only alongside a KPC**, the context the literature
  documents. Porin loss with no carbapenemase to amplify is not evidence of
  ceftazidime-avibactam resistance.

Avibactam combinations with a different partner drug (ceftibuten-avibactam,
aztreonam-avibactam, and the *P. aeruginosa* `mexR` set) are reported in the
mutation columns but are not scored into the ceftazidime-avibactam call.

## 6. Fosfomycin

* An acquired fosfomycin-modifying enzyme (fosA3/4/5/7/10/11, fosB, fosC2,
  fosL1) gives **Resistant**.
* `fosAKP`, the intrinsic chromosomal fosA of *K. pneumoniae*, is present in
  susceptible isolates and is **never** scored as resistance.
* Loss of function in an uptake or regulatory gene (`uhpT`, `uhpA`, `uhpB`,
  `uhpC`, `glpT`, `cyaA`, `ptsI`, `galU`) gives **Resistant**; if the affected
  gene runs off a contig boundary the call is **Indeterminate** instead,
  because an assembly break looks exactly like a truncation.
* Curated point mutations in these genes, for the declared organism, also give
  Resistant.

## 7. The three possible calls

| Call | Meaning |
|---|---|
| `Resistant` | A mechanism with established published evidence is present |
| `Indeterminate` | Something relevant was found but its effect is not established, or a target could not be assessed |
| `Susceptible` | The known mechanisms were looked for and not found |

`Indeterminate` exists so that "we do not know" is never silently rendered as
"susceptible".

## 8. The second opinion: GAMMA

GAMMA independently aligns the assembly against the same nucleotide database at
the codon level. Its positions are converted to the same numbering before
comparison, so agreement means agreement about the same residue. In the unified
report a change is 100% confidence when both callers report it and 50% when
only one does.

Amplicons found with `seqkit` are reported as **coordinates only**. Several
bundled primers are laboratory mutagenesis primers; a PCR product from them
says nothing about a clinical isolate's genotype, so no mutation is ever
inferred from amplicon presence.

## 9. Known limits

* **Draft assemblies.** A gene broken across contigs cannot be fully assessed.
  These are flagged, not guessed at.
* **Gene absence.** A gene missing from an assembly may be genuinely deleted or
  merely unassembled. Absence is not scored as resistance.
* **Expression.** Efflux upregulation and gene copy number affect real MICs.
  Copy number is reported; expression is not measured, and promoter/regulatory
  changes outside coding sequences are not examined. Porin and PBP3 changes are
  scored only as contributory evidence (section 5), never as a Resistant call,
  so an isolate whose resistance is driven purely by such a mechanism will read
  `Indeterminate` rather than `Resistant`.
* **Chromosomal point mutations for other species.** Only the three organisms
  above have curated positions. Other species get acquired-gene and KPC results
  only.
* **Novel mechanisms.** Anything not in the reference data cannot be found.
* **This is a genotypic prediction.** It is not a substitute for phenotypic
  antimicrobial susceptibility testing.

## 10. Checking it yourself

`create_test_genomes.py` builds synthetic assemblies with a declared expected
result (`expected_results.tsv`), and `tests/test_scenarios.py` runs the whole
pipeline over them and asserts that the expectations are met. `tests/` also
covers the variant caller directly, including Ambler numbering, indel handling,
strand handling and contig boundaries.

```bash
python3 -m pytest tests/ -q
```
